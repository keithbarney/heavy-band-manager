# Band Practice 1.3.0 (8)

## What's new

- Choose Automatic availability from your calendar or Manual availability from your usual weekly days and hours.
- Finish onboarding with clear availability setup and calendar connection, so scheduled practices appear on your calendar.
- Settings now shows the controls relevant to your availability method, with band rules grouped separately for organizers.

## Release dependencies and validation

- Deploy `supabase/migrations/20260908090000_add_weekly_availability.sql` before testing this build with production accounts.
- Run `make preflight` and the CI database suites, including weekly availability ownership and visibility checks.
- Simulator preview code is restricted to Debug simulator builds with `ONBOARDING_PREVIEW`; Release uses real authentication and services.
- Before customer release, verify both availability methods and practice calendar creation on a physical device against the migrated backend.
- The current implementation projects weekly availability six months ahead. Date exceptions, automatic horizon extension, and atomic source-switch RPCs remain follow-up work described in `docs/plans/weekly-availability.md`.

App Store Connect upload and production migration status must be confirmed separately; pushing this code does not deploy the database.
